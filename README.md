Each demo plays the clips side by side, and "Try it live" opens the interactive mock with the change applied. The table is generated by `_tools/sync.py`.

Work locally with `python3 _tools/serve.py` (http://127.0.0.1:4173/), or double-click `index.html`. Rules, naming and recording are in [AGENTS.md](AGENTS.md) and `docs/`.
