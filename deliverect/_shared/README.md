# _shared

Used by every Deliverect redline, before and after.

- `fixtures.js`: scenario orders (Rohan, Ronan, items).
- `motion.js`: easing, row exit, arriving flash, board fade, picked-up hold (`onPickedUp`).
- `frame.css`: hides app chrome in framed pages; row outlines.
- `stage.json`: name, label, mock URL. `frame.css` is linked by the mock itself when it is framed (the stage).
- `redlines.js`: generated by `_tools/sync.py` from the README table. Do not edit.
