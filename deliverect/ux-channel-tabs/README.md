# Channel tabs

**Problem** Couriers usually say their platform first ("DoorDash for…"). The list already has a channel filter, but it is a multi-select dropdown: open, tick, close, and untick later.

**Change** One-tap channel tabs above the list, with a count on each: All channels, then each channel that has orders. The list filters in place and the rest glide up. The selection survives status changes.

**Caption**

> Couriers lead with the platform: “DoorDash pickup.” Filtering by it today means opening a dropdown and ticking a box. My fix: one-tap channel tabs with counts above the list. Tap DoorDash, see only DoorDash orders.
