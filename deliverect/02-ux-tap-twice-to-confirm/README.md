# Tap twice to confirm

**Problem** One tap on "Picked up" completes an order immediately, with no undo.

**Change** The first tap arms the button for 3 seconds (amber, with a draining hairline). A second tap at least 350 ms later confirms. A quick accidental double tap only arms it.

**Caption**

> If swiping feels like too much, confirm twice instead. The first tap turns the button into Tap again for three seconds, and the second tap completes the order.
