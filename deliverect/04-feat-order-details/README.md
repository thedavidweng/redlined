# Order details on tap

**Problem** Order rows are not tappable, so staff cannot check what is in a bag from the list.

**Change** Tapping a row expands its items and notes inline directly under it. Height animates and items cascade in; the action button keeps working.

**Caption**

> Checking what items are in a bag should not force staff to leave the pickup screen. Tapping an order expands the items and kitchen notes right there so anyone can verify a ticket without losing their place.
